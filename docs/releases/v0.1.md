게임보이 「Kid Icarus: Of Myths and Monsters」 북미·유럽 공용판의 첫 한글 패치입니다. 영문 원문을 기준으로 번역했습니다.

**수정하지 않은 원본 영문 ROM용 통합 IPS 패치입니다.**

## 변경 사항

- 대사 39개 전부와 타이틀·부제·오프닝을 한글화했습니다.
- 메뉴·상태창·결과 화면·저장 질문·일시 정지·게임 오버·엔딩 문구를 한글화했습니다.
- Galmuri 글꼴을 ROM에 내장했습니다. 별도의 시스템 한글 폰트는 필요하지 않습니다.
- 게임 데이터를 추적하지 않는 소스 프로젝트와 재현 가능한 빌드·검증 도구를 구성했습니다.

## 배포 파일

| 파일 | 설명 |
|---|---|
| `KidIcarus_KO_v0.1.zip` | IPS, 해시 확인용 Python 패처, 설명서, 릴리즈 노트, MIT/OFL 라이선스 |
| `KidIcarus_KO_v0.1.ips` | 원본 영문 ROM에 직접 적용하는 통합 패치 |

파일은 `python tools/make_release.py v0.1`로 로컬 `release/`에 생성합니다.

## 검증 및 제한

PyBoy 2.7.0에서 대사 39개를 두 팔레트로 전수 검사하고 주요 화면과 마지막 엔딩까지 확인했습니다. 일부 장면은 RAM으로 지정했습니다. 전 구간 직접 클리어와 실기는 검증하지 않았습니다.
