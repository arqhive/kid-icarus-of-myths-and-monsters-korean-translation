# v0.1 검수 범위

## 2026-10-01 갱신

받침 분리 대사 글꼴과 UI 글꼴 분리 이후의 ROM은 mGBA에서 오프닝·타이틀, 힌트 방 대사, 상태창, 남은 기회 화면을 직접 확인했습니다.

`tools/verify_build.py`는 에뮬레이터 자동 조작 없이 ROM 데이터만 검사합니다.

- 원본 SHA-256, ROM 크기·카트리지 타입, 헤더 및 전체 체크섬, IPS 적용 결과, 추가 뱅크 번호
- 원본 뱅크 0–7에서 허용한 패치 위치 밖의 변경이 없는지
- 대사·상태창·남은 기회·엔딩 연결 코드, 줄 간격·시작 위치·상자 지우기 패치, 뱅크 10 대사 루틴
- 대사 39개를 ROM 데이터로 재현해 번역문, 위 글자·받침 그림, 가운데 맞춤, 상자 여섯 줄 이내인지
- 스테이지 글꼴에서 가타카나 칸 말고는 원본 그림이 바뀌지 않았는지, UI 라벨·스프라이트 글자가 맞는 그림을 가리키는지
- 타이틀 ™ 타일, 일시 정지와 엔딩 글자

결함을 일부러 넣은 사본(NPC 타일, 받침 글자, 원본 뱅크의 임의 바이트, ™ 타일)은 모두 실패로 잡히는 것을 확인했습니다. 아래 이전 기록의 PyBoy 장면 검사는 더 이상 사용하지 않습니다.

## 2026-09-28~29 (이전 구조, PyBoy)

2026-09-28~29 작업 기준입니다. `tools/verify_build.py`는 ROM을 새로 실행해 아래 항목을 재검사하고 로컬 `work/full/verification.json`에 결과를 씁니다.

- 원본 SHA-256, ROM 크기·카트리지 타입, 헤더 및 전체 체크섬
- IPS를 원본에 적용한 바이트 결과와 최종 ROM 일치
- 오프닝·타이틀 화면이 중간 한글 빌드와 일치
- 초반 이동·점프·공격 화면이 중간 빌드와 일치
- 39개 대사의 화면 맵과 모든 글자 타일, 일반/엔딩 두 팔레트에서 전수 비교
- 실제 상점 출력, 일시 정지·상태창, 게임 오버·남은 기회
- 결과 화면, 저장 질문과 예/아니오, 예 선택 후 저장 표식과 다음 구역 이동
- 엔딩 시작에서 마지막 연출까지 실행, 마지막 한글 문구의 맵·글꼴 비교

초기 조사에서는 원본 8뱅크의 그래픽 타일을 시각적으로 검토했습니다. 최종 점검에서는 원본 128 KiB와 결과 256 KiB의 문자 후보를 두 게임 문자표와 ASCII로 검색하고, OAM 문자와 출력 뱅크도 확인했습니다. 새로 번역할 게임 문구는 발견되지 않았습니다. 미사용 원문·알파벳·복사본은 결과 ROM에 남아 있습니다.

전체 대사와 후반 장면 검사에는 RAM으로 장면을 지정하는 방법도 사용했습니다. **전 구간 직접 플레이, 모든 분기의 연속 플레이, 실기 검증을 대체하지 않습니다.** 테스트 중 사용자 배터리 세이브는 쓰지 않습니다.

## 소스 프로젝트와 배포본 검증

Git 추적 파일만 별도 폴더에 복사하고, 원본 ROM·고정 글꼴·외부 Python 의존성만 제공한 상태에서 빌드·에뮬레이터 검증·v0.1 패키징을 다시 실행했습니다. 기존 작업 폴더의 한글 ROM이나 추출 데이터 없이 같은 결과 SHA-256을 재현했습니다.

배포 ZIP을 풀어 동봉 패처로 원본에 적용한 결과도 같은 ROM이었습니다. 다른 원본을 넣으면 출력을 만들지 않고 거절하는 것을 확인했습니다. Git에는 게임 ROM·화면·세이브·패치 산출물이 포함되지 않습니다.
